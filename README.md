# Liquid Glass Landing

Y2K-лендинг для ИИ-агентства на React + Vite.

- **Liquid glass** — искажение фона через SVG-фильтр `feDisplacementMap` поверх живого контента
- **Чат-виджет** — сценарный диалог, который квалифицирует заявку без бэкенда
- **Анимации** — Framer Motion и плавающие 3D-объекты

```bash
npm install
npm run dev
```

Стек: React 18, Vite 5, Framer Motion, Sass.
